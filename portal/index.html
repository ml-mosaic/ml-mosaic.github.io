API reference

One endpoint makes sprites: POST /api/generate, which returns a PNG. Sign in with an API key, or put "email" + "password" in the body instead. API home: (for browsers; code talks to the direct address).


      

        
FIELDTYPEWHAT IT DOES

        
prompttext, 1-300What to draw. Creatures, items, plants, buildings and tiles work best.

        
creativity0-1, default 0.50 sticks closest to the prompt, 1 is loosest.

        
seedwhole number, optionalSame seed + prompt + creativity = the same sprite. Leave out for a random one.

        
scale1-16, default 1Upscales the 64×64 result with crisp pixels.

        
Authorization: Bearer MOSAIC_...headerAn API key (make them on the keys page), or api_token in the body.

      

    

    

      
Responses

      

        
200The PNG. X-Seed is the seed it used; X-Quota-Remaining what's left today.

        
401The key is wrong or revoked, or the email/password don't match.

        
422A field is missing or out of range.

        
429Today's allowance is used up (it refills at 00:00 UTC), or too many failed sign-ins from one address.

        
503The model is waking up or very busy: try again in a minute.
