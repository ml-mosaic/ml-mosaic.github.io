API reference

One endpoint makes sprites: POST /api/generate, which returns a PNG. Sign in with an API key (below), or put "email" + "password" in the body instead.


      

        
FIELDTYPEWHAT IT DOES

        
prompttext, 1-300What to draw. Creatures, items, plants, buildings and tiles work best.

        
creativity0-1, default 0.50 sticks closest to the prompt, 1 is loosest.

        
seedwhole number, optionalSame seed + prompt + creativity = the same sprite. Leave out for a random one.

        
scale1-16, default 1Upscales the 64×64 result with crisp pixels.

        
Authorization: Bearer MOSAIC_... or api_tokenheader / textSign in with an API key (make them on the keys page)...

        
email (or username) + passwordtext...or with your account, instead of a key.

      

      

        
RESPONSE

        
200image/pngHeader X-Seed is the seed it used (send it back to get the same sprite); X-Quota-Remaining is how many you have left today.

        
401jsonThe key is wrong or revoked, or the email/password don't match.

        
422jsonA field is missing or out of range.

        
429jsonAll 15 of today's generations used (refills at 00:00 UTC), or 10 failed sign-ins from one address in 5 minutes.
